# Mental Well-being Score Prediction System

A fresh student SML project for predicting a numerical well-being score from lifestyle and well-being-related factors.

## Important
This is an educational machine-learning project. It is **not a medical diagnosis or clinical assessment tool**.

## Workflow
1. Data loading and understanding
2. Data cleaning
3. Exploratory data analysis
4. Statistical analysis / hypothesis testing
5. Feature engineering
6. Train-test split
7. Regression model comparison
8. MAE, MSE, RMSE and R² evaluation
9. Save the best model
10. Web application for prediction

## Dataset
Place the final dataset at `data/mental_wellbeing.csv` with a numerical target named `Wellbeing_Score`. We will finalize the dataset before training.

## Team

- Member 2: feature engineering, regression and evaluation
